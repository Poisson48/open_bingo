Deux builds officiels — choisissez selon votre appareil

Portable Linux

AppImage · x86-64 · Qt embarqué

Rien à installer : téléchargez, rendez exécutable, lancez. Idéal USB / PC sans droits admin.

chmod +x OpenBingo-*.AppImage
./OpenBingo-*.AppImage
Télécharger l’AppImage

Android

APK · arm64 · mises à jour in-app

Ouvrez l’APK sur le téléphone (autorisez la source) ou installez via ADB. Les releases se mettent à jour par-dessus.

adb install -r openbingo-*-arm64.apk
