Télécharger

Choisissez votre plateforme — aucune inscription requise

🖥 Linux — AppImage 📱 Android — APK

Linux (AppImage)

chmod +x OpenBingo-*.AppImage && ./OpenBingo-*.AppImage
Un seul fichier, Qt embarqué.

Android (APK arm64)

Ouvrez l'APK sur le téléphone ou adb install -r openbingo-*-arm64.apk. Mises à jour proposées dans l'app.
